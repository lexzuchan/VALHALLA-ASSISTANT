# Local edition roadmap

Included: local Qwen3 chat through Ollama, no API keys or paid fallback, compact
runtime settings, validated physics tools, simulation lab, local notebook,
text references, system read-aloud, and Windows setup/build scripts.

Not implemented: local speech recognition, vision/PDF extraction, CAD integration,
Python runtime, hardware automation, persistent calculation traces, multi-project
import, signed releases, and automatic application updates. These would need
separate implementation and testing; they are not hidden cloud dependencies.
