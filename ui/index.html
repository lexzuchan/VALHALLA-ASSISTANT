MODEST BY DESIGN

Private. Local. Practical.

A compact model

The recommended 4B model is about a 2.5 GB download. Actual memory and speed depend on your laptop. Setup-Lite-AI.cmd creates the same assistant with a smaller 1.7B base if needed.

Short, focused sessions

A 4,096-token context and limited answer length keep resource use modest. Only a short recent conversation window is included. The model unloads after one idle minute.

No paid fallback

This edition contacts only the Ollama service on 127.0.0.1:11434. Cloud model names and remote-model manifests are rejected. No credentials are used.

Clear limits

This text model cannot inspect images or PDFs. Paste extracted text instead. Voice dictation is disabled. Calculator results still need real-world engineering judgment.
