# Contributing

Use Node.js 22.12+ and Windows for desktop and packaging verification.
Run `npm ci`, `npm run check`, `npm run icons`, and `npm run smoke`.
Never add API keys, `.env` files, local project data, or generated installers.

Physics changes need an independent reference value, input bounds, explicit units,
model assumptions, and a regression test. Do not add arbitrary code execution
as a shortcut for AI tools. Keep user and document text untrusted and keep secrets
in the main process. Document new network destinations and user consent controls.

For interface changes, check 1000×700 and 1500×970, keyboard focus, reduced motion,
empty states, errors, and long messages. State what was tested and what still needs
manual verification in your pull request.
